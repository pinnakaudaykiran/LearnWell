# Learnwell

A student learning and career platform with AI lessons, flashcards, study tools, study circles, and career roadmaps.

## Run locally

1. Install Node.js and Ollama.
2. In this folder, run `npm install`.
3. In one terminal, run `npm run dev`.
4. In another terminal, run `npm run ai`.
5. Open http://localhost:5173 in your browser.

The AI tutor runs locally on your computer. Uploading the project to GitHub does not host the AI service.
